# Cosmic Assembly Laboratory

Exploratory control board for magnetodynamics and chemical assembly.

**Scientific status:** The published dashboard currently runs a toy stochastic model. Its score is not the formal molecular assembly index, and its magnetic coupling is hypothetical. The dashboard does not demonstrate any real magnetic effect on chemical complexity.

## Molecular assembly research sources
- https://github.com/ELIFE-ASU/assemblytheorytools
- https://github.com/DaymudeLab/assembly-theory
- https://github.com/croningp/assemblyphysics
- https://github.com/croningp/molecular_complexity
- https://doi.org/10.5281/zenodo.8017327

These are external research sources; their datasets have not yet been imported or validated.

## Roadmap

2. Validate formal assembly-index calculations.
3. Implement chemically balanced reaction networks.
4. Integrate measured magnetic-field data and uncertainties.
5. Distinguish observations, calculations, and speculative model outputs.
